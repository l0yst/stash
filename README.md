## Setup

+ **OS**      — arch linux
+ **WM**      — [awesome wm](https://github.com/awesomeWM/awesome)
+ **Shell**   — zsh
+ **Term**    — [wezterm](https://github.com/wez/wezterm)
+ **Editor**  — [neovim](https://github.com/neovim/neovim) + [zed](https://github.com/zed-industries/zed)
+ **Browser** — [zen](https://zen-browser.app)
+ **Fetch**   — [fastfetch](https://github.com/fastfetch-cli/fastfetch)
+ **Prompt**  — [oh-my-posh](https://ohmyposh.dev)
+ **Comp**    — [picom](https://github.com/yshui/picom)
+ **Music**   — [amberol](https://gitlab.gnome.org/World/amberol)
+ **Icons**   — [Tela Circle](https://github.com/vinceliuice/Tela-circle-icon-theme)
+ **Cursor**  — [Bibata](https://github.com/ful1e5/Bibata_Cursor)
+ **Theme**   — [SlateDust](https://github.com/l0yst/slatedust)

## Keybinds

| Keys | Action |
| --- | --- |
| `Super + /` | Show keybinds |
| `Super + Return` | Open terminal |
| `` Super + ` `` | Scratchpad terminal |
| `Super + a` | App launcher |
| `Super + x` | Power menu |
| `Super + c` | Kill window |
| `Super + Shift + space` | Toggle floating |
| `Super + Shift + r` | Restart awesome |
| `Print` | Screenshot |
| `Super + ,` | Clipboard manager |
| `Super + .` | Emoji picker |
